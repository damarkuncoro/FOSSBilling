# Software Licenses & Downloads

Clients purchasing digital software licenses, downloadable goods, or media assets can manage their keys and file downloads securely.

---

## 🔑 Software License Management (`/licenses`)

- **Serial Keys:** Formatted serial keys (e.g. `FOSS-XXXX-XXXX-XXXX-XXXX`).
- **Domain & IP Locks:** View the active domain name and server IP address bound to the license key.
- **License Lock Reset:** Clients can reset their license lock if migrating to a new server or domain.

---

## 📥 Secure Downloads (`/downloads`)

- Access purchased scripts, software builds, or documentation assets.
- Tokenized expiring download links prevent unauthorized file sharing.
