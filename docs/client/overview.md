# Customer Portal Guide: Overview

The FOSSBilling Customer Portal (`http://localhost:3001`) gives clients a seamless interface to browse hosting plans, register domains, pay invoices, manage software licenses, and access support.

---

## 🚀 Key Features for Customers

- **🛍️ Storefront & Domain Checker:** Search TLD availability and customize order options.
- **🛒 Interactive Shopping Cart:** Multi-item cart with promo codes and dynamic currency conversion.
- **🧾 Billing & Invoices:** View open/paid invoices, download PDF receipts, and add deposit funds.
- **📦 Service Management:** View hosting credentials, server nameservers, and reset software license bindings.
- **🎧 Support Helpdesk:** Open support tickets, attach error logs, and track resolution progress.
- **🌐 Multi-Language & RTL:** Change languages dynamically via the top navigation language switcher.
