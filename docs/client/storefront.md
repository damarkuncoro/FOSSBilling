# Storefront, Ordering & Cart

Clients can order web hosting, servers, digital downloads, and domains directly from the responsive storefront.

---

## 🛍️ Ordering Workflow

1. **Product Selection:** Select desired plan (e.g. Starter Cloud VPS, WordPress Hosting).
2. **Domain Configuration:**
   - Register a new domain (e.g. `mysite.com`).
   - Transfer an existing domain from another registrar.
   - Use an existing domain with custom nameservers.
3. **Custom Configuration Options:** Dynamic forms prompt for OS template, root password, or add-ons.
4. **Promo Codes & Checkout:**
   - Apply discount codes in the cart.
   - Select payment method (Stripe card, PayPal, Midtrans QRIS/VA, or account balance).
5. **Instant Provisioning:** Once payment is confirmed, service credentials are automatically generated.
