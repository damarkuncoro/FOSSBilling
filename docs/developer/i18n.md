# Internationalization (i18n) & Localization

FOSSBilling includes full multi-language and directional support across both backend APIs and React frontend portals.

---

## 🌐 Supported Locales

- 🇺🇸 `en_US` — English (United States) [LTR]
- 🇮🇩 `id_ID` — Indonesian (Bahasa Indonesia) [LTR]
- 🇩🇪 `de_DE` — German (Deutsch) [LTR]
- 🇫🇷 `fr_FR` — French (Français) [LTR]
- 🇪🇸 `es_ES` — Spanish (Español) [LTR]
- 🇯🇵 `ja_JP` — Japanese (日本語) [LTR]
- 🇸🇦 `ar_SA` — Arabic (العربية) [RTL]

---

## ⚙️ Backend Locale Negotiation (`pkg/i18n`)

The `LocaleMiddleware` inspects:
1. `?locale=` query parameter
2. `X-Locale` header
3. `BBLANG` / `locale` cookie
4. Standard `Accept-Language` HTTP header

---

## 🖥️ React `useTranslation()` Hook

In frontend components:

```tsx
import { useTranslation } from '@/lib/i18n';

export const MyComponent = () => {
    const { t, locale, setLocale, currentLocaleInfo } = useTranslation();
    return <h1>{t('dashboard')}</h1>;
};
```
