# Extensions & Marketplace

FOSSBilling includes a built-in Extension Manager and Marketplace Hub to install, configure, and update modular capabilities.

---

## 🧩 Extension Types

1. **Modules:** Core capability modules (Antispam, Formbuilder, Cookie Consent, Mass Mailer, SEO).
2. **Payment Gateways:** Integrations with payment processors.
3. **Server Provisioners:** Drivers for remote control panels and cloud APIs.
4. **Domain Registrars:** Adapters for domain registration providers.
5. **Themes & UI Extensions:** Custom templates and widgets.

---

## 🛒 Installing Extensions

1. Navigate to **Extensions** (`/extensions`) in the Administrator Portal.
2. Select the **Marketplace** tab to browse published extensions with community ratings and download metrics.
3. Click **Install** next to the desired extension.
4. Open extension settings to input any required API keys or credentials.
